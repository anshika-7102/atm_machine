# Kaggle Dataset Bundle: ATM Cash Demand Predictor

This bundle contains the clean, unified, multi-feature dataset ready to be uploaded to Kaggle as a new Dataset.

## Dataset File:
* **`atm_demand_enriched.csv`** (8,461 rows × 41 columns)
  * Multi-ATM daily demand time-series across 20 ATMs from June 2017 to September 2018.
  * Target variable: `demand` (Gross cash withdrawal demand, strictly non-negative).
  * Enriched features: ATM GPS coordinates, location type, calendar signals, Russian public holidays, daily temperatures, precipitation, snowfall, and simulated cash balances.

## How to Upload to Kaggle:
1. Go to [kaggle.com](https://www.kaggle.com) and click **Create** > **New Dataset**.
2. Drag and drop `atm_demand_enriched.csv`.
3. Set the Title as: `ATM Cash Demand Enriched Dataset`.
4. Click **Create**.
5. In your Kaggle Notebook, click **Add Data** (top right) and search/select your newly created dataset.
